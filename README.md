## סנכרון בין מכשירים
הגדרות ← "הפעלת סנכרון במכשיר הזה" ← סורקים בטלפון את קוד ה־QR. כל שינוי עובר בין המכשירים תוך שניות, גם אחרי עבודה בלי אינטרנט. הקוד/הקישור הם המפתח לנתונים — לא לשתף.

## טופס הזמנות ללקוחות
דף "טופס הזמנות" ← "יצירת הטופס שלי". מקבלים קישור קבוע לשליחה ללקוחות. שם קובעים מוצרים, מחירים, טעמים, ימים ושעות איסוף, ימים מראש, תקרת הזמנות ליום, תאריכים סגורים, משלוחים, מינימום ותנאים. כל הזמנה נכנסת לאפליקציה לבד, עם צליל והתראה.

תשלום: אפשר לדרוש מקדמה (אחוז לבחירה) או תשלום מלא בביט/פייבוקס. אחרי השליחה הלקוחה רואה את הסכום וכפתורי תשלום ולוחצת "שילמתי"; ההזמנה נשארת "ממתינה לתשלום" עד שמאשרים באפליקציה שהכסף נכנס.

## איך מחושב התמחור
עלות מלאה = חומרי גלם + אריזה + תנור ושונות + **שכר שעתי × זמן עבודה פעילה** (הכנה + עיצוב).
מחיר מומלץ = עלות מלאה ÷ (1 − יעד רווח), מעוגל לשקל, כולל מע״מ אם את עוסק מורשה.
את השכר, עלות התנור ויעד הרווח קובעים ב"הגדרות".

## תצוגה

## חשוב
- בלי סנכרון, הנתונים נשמרים רק בדפדפן של המכשיר. עם סנכרון — יש עותק בענן (Supabase, פרויקט al-hagesher-orders).
- מחירי המצרכים ההתחלתיים ומחירי המכירה במתכוני הבסיס הם הערכה — עדכני לפי הקבלות והשוק שלך.
- התווית המודפסת היא עזר; את הדרישות המחייבות לסימון מזון יש לבדוק מול ת״י 1145 ומשרד הבריאות.
